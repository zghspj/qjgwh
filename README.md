# 电子名片系统 · 中国林业与环境促进会

青健工委会官方电子名片系统，支持成员管理、名片设计、二维码核验。

---

## 📇 功能模块

| 页面 | 功能 | 说明 |
|------|------|------|
| 🏠 [首页](/) | 导航入口 | 所有工具的汇总入口 |
| 🌱 [管理后台](/admin.html) | 成员管理 | 添加/编辑/删除成员信息 |
| 🎨 [名片设计器](/designer.html) | 名片设计 | 拖拽式设计名片布局 |
| 📱 [二维码生成器](/qrcode.html) | 二维码生成 | 生成核验二维码，可下载PNG |
| 👁️ [名片预览](/card.html) | 名片展示 | 查看设计好的电子名片 |
| 🔒 [身份核验](/verify.html) | 官方核验 | 客户扫码核验身份 |

---

## 🚀 快速开始

### 1. 添加成员
打开 `admin.html`，填写成员信息（编号、姓名、职务等），点击"添加/更新成员"。

### 2. 设计名片
打开 `designer.html`，选择成员，拖拽元素设计名片布局。

### 3. 生成二维码
打开 `qrcode.html`，选择成员，生成核验二维码，下载PNG图片。

### 4. 客户扫码核验
客户扫描二维码，跳转到 `verify.html`，显示成员真实身份信息。
